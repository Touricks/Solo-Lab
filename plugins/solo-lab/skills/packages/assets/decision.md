# 决策包模板（任一序列 +2 → 研究员）

研究员拍板的事都写成决策包，再由书记员建成决策工作项。要研究员亲手做的事，比如整理数据、挂 API、开 Docker，也写成决策包，包头“执行方”写“研究员”，要他做的写在“研究员要做的事”一行。决策包有两个来源，用同一份模板：

| 来源 | 谁写 | 工作项怎么建 | 包头的“渠道” |
| --- | --- | --- | --- |
| 决策队列 | 遇到超出授权的事的序列 +2 | 登记后停在“待决定”，进决策队列；研究员定了以后，书记员确认“决定”这一步 | 决策队列 |
| 研究员主动发起 | 研究员在入口或某个 +2 的会话里当场定下事情时，参与对话的那个 +2 | 登记后接着确认“决定”这一步 | 研究员主动发起 |

两条路确认“决定”这一步时，都要填决定内容和决定人。要记的是会改变其他会话做法的决定，比如改目标、改验收标准、改规格、动资源或者新增约束；只影响当前会话内部做法的，不用记。

每条决策走三步：待决定、待执行、归档（已执行）。空间里的“已决定”就是待执行：研究员定了，书记员马上确认“决定”这一步，并通知执行方，各会话就知道选了哪个选项。包头“执行方”是会话的，书记员把决定内容发给它，它照决定执行完，马上请书记员归档，不在待执行里停留；执行方是研究员的，他在入口会话说做完了，书记员才归档。

研究任务有三处要用决策签字：验证流程第 4 步的假设和阈值，第 9 步的下一步，以及任何一次回退。用来签字的决策要写明“所属研究任务”，研究员定了以后，“签字结果”填批准或退回。书记员确认那一步或回滚之前，脚本核对这条决策已经决定、签字结果是批准、所属研究任务对得上，并且是在任务走到那一步之后决定的。三处各写一条，任务走到那一步以后再送：一条决策只过一次关。

## 模板

```markdown

- 包类型：决策包
- 渠道：决策队列 / 研究员主动发起
- 紧急程度：插队 / 今天 / 本周 / 可延后
- 所属研究任务：#<研究任务的工作项 ID>（用来签字的必写；和哪条研究任务都无关的不写这一行）
- 发出方：<序列> +2（会话名）
- 接收方：研究员
- 关联工作项：待建
```

## 填写规则

- 决策队列来的决策包，“决定”一节先空着，研究员定了以后由书记员补上，并和工作项上的决定内容、决定人一致。
- 研究员主动发起的决策包，“选项”和“建议”写谈话里比较过的做法；没比较过就写“无”，不补编选项。“决定”一节当场写全。
- 选项至少两个，其中一个可以是“不做”。
- 包头“研究员要做的事”写这条决策定下以后要研究员亲手做的事，比如整理数据、挂 API、维护沙箱、开 Docker、调设置。没有要研究员亲手做的，写“无”。包检查要求决策包有这一行。
- 包头“执行方”写这条决策定下以后由谁执行：要研究员亲手做事的，写“研究员”；不用他亲手做的，写执行它的会话名，多半是发出方，比如 `Alg-p2-01`，只写名字、不加说明。执行方是研究员时，“研究员要做的事”不能是“无”；执行方是会话时，“研究员要做的事”写“无”。缺了“执行方”这一行，或者两行对不上，包检查会退回。
- 执行方是研究员的，研究员定了以后它留在决策队列里，`ledger.py query queue` 把它列成“待执行”；研究员做完了，在入口会话说一声，入口带着他的原话请书记员归档，书记员在评论里记下他做了什么。被决策卡住的工作项照旧记阻塞，阻塞原因写“等研究员：决策 #<ID>”，决策归档以后清掉。
- 执行方是会话的，书记员确认“决定”时把决定内容发给它；它照决定执行完，马上请书记员归档，不在待执行里停留。
- 紧急程度决定在队列里的位置。决策登记进队列时，入口在那一轮提一次，“插队”的可以当场问研究员一次；研究员主动来谈时，入口把待决定的决策和等研究员执行的决策全部列给他。决策不会过期，一直等到研究员决定。
- 背景只写做决定需要的信息，详细材料放进事实依据。
- 涉及签字的，附待签版本的链接和版本号。验证流程第 4 步的签字一次冻结需求文档、评测集版本、规格和总预算，这几样的链接和版本都列在这里。
- “受影响的工作项”要写全。入口据此通知负责这些工作项的会话；漏写的，那些会话就不知道这件事已经定了。

## 各序列常见的决策包

| 序列 | 常见事项 |
| --- | --- |
| 产品 | 判据要改；试点要不要扩大；选题组合调整 |
| 算法 | 假设和阈值签字（验证流程第 4 步）；回退；超出授权的转向 |
| 工程 | 超预算；会影响多个项目的共享组件改动 |
| 基础设施 | 权限策略和身份方案签字；追加配额 |
| 质量 | 冻结以后评测协议和证据标准的变更；和别的序列的争议 |
| 项目管理 | 下一步签字（验证流程第 9 步）；台账结构、任务包模板等组织规则变更 |
| 外联 | 发给导师和合作人的材料签字；材料模板调整 |
